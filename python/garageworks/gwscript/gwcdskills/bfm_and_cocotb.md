# Axi4Lite32BFM — Scala test API

Every generated spec file (`<Top>GWCDSpec.scala`) drives the GWCD's
AXI-Lite port through `garageworks.Axi4Lite32BFM`, exactly like
`AxiGCDSpec.scala` (canonical example 2's spec):

```scala
class YourGWCDSpec extends AnyFlatSpec with ChiselSim {
  val const1val = 0x........L
  val const2val = getGitHash
  val p = YourGwcdParams.default(const1val, const2val)

  "test YourGWCD" should "pass" in {
    simulate(new YourGWCD(p, debugprint = true)) { dut =>
      val bfm = new Axi4Lite32BFM[YourGWCD](dut)
      bfm.initMaster()

      bfm.expectVal(p.const1_r, const1val)
      bfm.expectVal(p.const2_r, const2val)

      // ... exercise the register map ...

      bfm.softReset(p)

      println("YourGWCD test passed!!")
    }
  }
}
```

API surface (all methods take a byte-offset register address, matching the
params case class fields):

- `bfm.initMaster()` — must be called once before any read/write.
- `bfm.writeVal(addr: Long, value: Long): Unit` — full 4-byte AXI-Lite write.
- `bfm.readVal(addr: Long): BigInt` — AXI-Lite read, returns the raw value.
- `bfm.expectVal(addr: Long, expected: BigInt, msg: String = ""): Unit` —
  reads `addr` and asserts it equals `expected` (use for `const1_r`/
  `const2_r` sanity checks and any deterministic register).
- `bfm.softReset(p: YourParams): Unit` — writes `p.soft_reset_rw`, then
  polls it until the reset-done bit reads back `1`.

For registers whose value only becomes valid asynchronously (e.g. a
"done"/"valid" flag after starting a computation), poll in a bounded loop —
see `runGcdTest`'s `while (valid == 0 && tries < 1000)` pattern in canonical
example 2's spec — never an unbounded `while`.

## cocotb bridge (not generated by --gwcd)

`--gwcd` only generates the Chisel wrapper and its ScalaTest spec. The
cocotb testbench (`gwtests/`) that exercises the same register map under
Verilator is scaffolded separately by `gwscript`'s setup wizard
(`setup_wizard._scaffold`) once `--gwcd` hands off a working `chiseltop=`;
it is out of scope for the files you generate here.
